# ProtoCross Examples

This repository accompanies the blog at [ProtoCross.dev](https://protocross.dev/). Each example contains the source and build instructions you need to follow along with its post.

- [ValueWithUncertainty, Part 1](UncertaintyDemo/README.md#part-1-factories) shows how to write factories in ProtoCross and call them from C# and C++.
- [ValueWithUncertainty, Part 2](UncertaintyDemo/README.md#part-2-functions-and-unit-tests) shows how to write ProtoCross functions and unit tests, then run the same tests in C# and C++.
